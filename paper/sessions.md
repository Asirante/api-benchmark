## 주의할 세션

- `exp_20260915_030551` 의 데이터 품질 열은 옛 manifest 형식(저장률 열 없음) 때문에 0 으로 집계됩니다. 실제로는 **개방 루프 640 rps 이상 16회에서 InfluxDB 저장률이 0.002~0.975** 로 미달했습니다(`summary_diagnostics.csv` 의 `influx_completeness`). 해당 실행의 TC 별 지연은 사용할 수 없고, 처리량·dropped·전체 백분위수는 k6 요약(JSON)에서 가져왔습니다.
- `exp_de_pilot` 은 VM 단조 시계가 약 10% 느린 상태에서 측정되었습니다. 기능 확인 용도로만 쓰고 측정값은 사용하지 않습니다.
- `exp_de_20260916_1144` 는 재부팅으로 중단되어 완료 실행이 없습니다(진행 중이던 1회의 InfluxDB 데이터도 삭제).
- 480 rps 대조는 풀 20:20 이 `exp_de_20260916_1154`, 풀 500:100 이 `exp_de_20260916_0241` 로 **세션이 다릅니다**. 표 B·`pool_size_table.md` 에 출처를 표기했습니다.
- 표 C 의 800 rps 행은 `exp_de_20260916_1154`, 900~1200 rps 행은 `exp_de_cap_20260918_0345` 입니다.
