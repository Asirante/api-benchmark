🚀 1. 기본 아키텍처 비교 (TC 1 ~ TC 7)

REST, GraphQL, gRPC(Direct)의 성능을 비교합니다.

[TC 1] 단순 조회 (Simple Read)

Query A (REST, GQL):

SELECT mean("value") FROM "http_req_duration" WHERE "tc" = 'tc1' AND $timeFilter GROUP BY time($__interval), "api" fill(null)
